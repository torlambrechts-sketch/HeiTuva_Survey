# V2-5 → V2-8 — one Gate 6 report for four phases

**Written 2026-09-10, retrospectively.** V2-5 (blind-spot tasks), V2-6 (help centre),
V2-7 (test mode) and V2-8 (Bruksområder + splash fidelity) each closed without the Gate 6
report `CLAUDE.md` requires. They are exactly the four that ran as one continuous session,
at Tor's instruction — **the instruction removed the report; this was not an oversight
inside the phases**, and the distinction matters because it says what is recoverable.

**Why one report and not four.** Four retrospective reports would read like evidence and
be recollection. What a Gate 6 report is *for* is that its claims were made while the work
was in front of the person making them; written a day later, four of them would have the
form of that guarantee without the substance. One report, with a hard line through it
separating what can still be derived from what cannot, is worth more than a plausible
reconstruction — and the line is § 0.

**STATUS: CLOSED RETROSPECTIVELY.** Deliberately *not* «READY FOR REVIEW»: that marker
means a verification pass and a fix pass were run and reported at the time, and for these
four they were not reported even where they were run. Using the standard marker here would
make this report indistinguishable from the eight that earned it.

tsc, eslint and the browser gates all run in CI on every push since S2 scheduled the

blockers in `verify:responsive` within one run of the gate existing — a gate that had never
run had been silently failing.

## § 5 — What this report does not do

It does not assert a verification pass or a fix pass occurred per phase, because the
repository cannot say so. It does not re-open the phases: the two-pass rule closes a phase
after its two passes, and anything found from here is next-phase work, logged in
`docs/v2/06-remainder.md § 5`.

**The one thing worth carrying forward** is that a continuous session is a legitimate way to
run four phases and an illegitimate way to skip four reports — the reports are cheap while
the work is in front of you and unrecoverable a day later. If phases are run continuously
again, the report per phase is the part that must not be batched.
