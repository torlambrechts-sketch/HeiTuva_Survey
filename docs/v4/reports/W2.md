## What was built

**The arithmetic is a pure function, and that is the design decision.** `computeShow` and
`parseModuleCookie` live in `lib/workspace/modules.ts` with no server imports, because switching a
module off **changes its row's grid template** — the survivor grows from a column to full width —
which is a layout change at every breakpoint rather than a `display:none`.

**All sixteen row combinations are enumerated in the test**, not spot-checked. `nps` and `quiz`
have no card yet, so a test driven through the page would leave half the templates unexercised; the
purity exists so the app's limit does not become the test's limit. Row B's asymmetry is pinned
explicitly — `minmax(0,1.6fr)` beside `minmax(280px,.9fr)`, a list that wants width beside a card
that needs a floor.

**The cookie keeps two states apart that would otherwise collapse.** Absent = «nothing chosen»,
falling back to the workspace's own set; `[]` = «chose nothing», which is the empty panel. A
catch-all would have destroyed the distinction and made the empty state unreachable, so the
conditions are named one by one — not-JSON, not-an-array, not-strings each return `null` — and
unknown keys filter **against the registry**, so a key retired by a migration stops being shown
with no further edit.

**Q124 is a join, not a copy.** The strip's chip reads `dashboard_presets.title` through
`preset_key`, so a renamed preset stays correct. Tilpasset has no preset and renders the other
sentence.

**The seed carries the half it can.** `organizations.workspace` on both demo orgs, **different on
purpose**: `hr` for Nordisk Studio and `cx` for the other — and `cx`'s set is `nps + activity +
action`, two of which have no card, so the seed also carries the case where a workspace
legitimately shows less than it names.

## Two things named so they are not mistaken for oversights

- **A null workspace renders every module** — exactly the pre-W2 behaviour — written once as
  `computeShow` over every key rather than as a second branch beside each card. The strip is
  **absent rather than faked** in that state: a strip naming a workspace that does not exist is
  indistinguishable from a real one.
- **The `nps` and `quiz` Oversikt cards are not built.** They are new surfaces rather than gating,
  and the nps card's critics list is «Kunde 4812 · sak #2291» — which **Q120 decided is not built**.
  Selecting the Quiz workspace today therefore shows only Svaraktivitet. That is the real state
  rendered honestly, and it is a consequence worth knowing before anyone demos it.
