were checked before removal** — `OverviewScreen.tsx:111`, `undersokelser/page.tsx:186` — because a
control removed from the only place it exists is a feature deleted, and from the third place it
exists is fidelity. The test asserts absence and presence together; the presence half is the
non-vacuity guard.

## Three test-shape slips, all mine, all caught by running them

1. A slice keyed on `indexOf('<select')` measured the **JSDoc** above the element — the same defect
   as W0's write test one commit earlier.
2. Its replacement used `/\btouch-44\b/` and matched **inside** `touch-44-field`, because `-` is a
   non-word character. **Third outing for the `\b` family**, and the first with nothing to do with
   alphabets. A CSS class is a token in a space-separated list; the test compares tokens.
3. `not.toMatch(/<WideToggle/)` contradicted the next test in the same block — the toggle *is* in
   the file, as a slot. Restated as the property the component can honour.
