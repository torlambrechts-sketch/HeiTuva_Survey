## The phase's finding: the cross-workspace capture earned itself immediately

```
[blocker] oversikt/arbeidsflate-kunder @320px — scrollWidth 338 > clientWidth 320
```

**It overflowed only in `cx`.** The `hr` default and both Tilpasset states passed at the same
width. This is exactly what capturing across workspaces was asked for, and it appeared on that
capture's first run.

The arithmetic names the cause without guessing:

```
«Dashboard følger oppsettet «Arbeidsmiljø»»      41 chars   (hr)
«Dashboard følger oppsettet «Kundeopplevelse»»   44 chars   (cx)
                                                  3 chars
three characters at 11.5px semibold   ~18px
measured overflow                      18px      (338 − 320)
```

The layout-note chip carried the bundle's `flex-none` **and** `whitespace-nowrap` (V4:278) — both
correct at ≥1280px, and together making the chip unable to *either* shrink or wrap. Its width was
therefore decided by **a registry value that differs per workspace**. Both are `xl:` rules now.

**The shape is enumeration row 10 one level out**: a constant correct in the context it was
measured in, carried where the thing it constrains has a different size. Here the constant is a
*layout rule* and the varying thing is a **word** — a preset's title, which nobody thinks of as a
dimension until it sets one.

## What was built

**Four sites, measured off the bundle** — `V4:1024` `builder.previewTitle`, `:2288`
`tasks.taskChannels`, `:3021` `admin.defaultRespondentLang`, `:3218` `send.recipients`.

**The scope boundary is itself a finding.** Thirty shipped strings name the respondent; v4
substitutes at **four**. Several of the others are respondent-facing, where the standing constraint
forbids it outright. «Replace every occurrence» is the natural reading and would have broken the
invariant this phase exists to hold.

**A Norwegian inflection trap**, caught by reading both strings rather than substituting: the
bundle writes «Kommentarer fra {{ wsPersons }} samles her» → «fra **ansatte**», the *indefinite*
plural; our string had «respondent**ene**», the definite. A naive substitution yields «fra
ansatt**ene**». This is also why `person` / `personDef` / `persons` are three columns and only
`personsCap` is derived — it is the one mechanical form.

**`tsc` cannot see any of this.** next-intl does not type-check ICU arguments, so parameterising
four strings compiled clean while every one would have rendered a literal `{personDef}`.

**`send.recipients` is a copy change, not a substitution** — v3:3103 was «Mottakere».

**`M:0104`** — `workspace_use_case_lifts`, a join to `use_cases` in Q45's shape, so a lift *cannot*
name a use case that does not exist. Measured before writing: all four of the bundle's lift values
were already `use_cases` keys. `liftOrder` is **stable, and that is load-bearing** — the list
arrives in editorial order and every pack keeps its position within its group.

**The constraint was strengthened in this phase**, which was the instruction and is the right
order: `app/s/` is now forbidden the names W3 *created*, not only those W0 could know. And it has a
non-vacuity half — the four marked pairs are asserted present — because an absence test otherwise
passes when the feature does not exist rather than when it is contained.
